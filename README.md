# Job Search AI Assistant (TS)

ユーザーの保有スキルとキャリアイメージから、AIが最適なアドバイスを生成するフロントエンドツールです。   
GitHub Pagesでツールを公開しているため、本リポジトリは**Public**にしています。   
リポジトリをPrivateにすると、ツールが非公開になるため注意してください。   

## 🛠 技術スタック
- **Frontend**: React 19 (TypeScript)
- **Build Tool**: Vite
- **Styling**: Tailwind CSS v4
- **Documentation**: MkDocs (Docs as Code)
- **Hosting**: AWS Amplify / GitHub Pages (Planned)

## 🚀 クイックスタート

### フロントエンドの開発
```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev
```

### ドキュメントの閲覧（MkDocs）

```bash
# 依存関係のインストール (Python環境)
pip install -r requirements.txt

# ローカルサーバーの起動
mkdocs serve
```
